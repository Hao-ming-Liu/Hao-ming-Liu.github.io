# 个人主页设计说明书

> 日期：2026-06-28
> 状态：已确认

---

## 1. 项目目标

为编程初学者（有 C/C++ 基础，零 Web 经验）搭建一个**综合个人主页**，包含个人介绍、博客列表、作品展示功能。目标是快速看到成果，同时在动手过程中掌握 HTML/CSS 基础。

## 2. 用户画像

- 会 C/C++，能理解变量、函数、结构体等概念
- 零 HTML/CSS 基础
- 关注 UI 美观和导航流畅度
- 先搭框架，后续逐步填充内容和深入学习

## 3. 技术选型

| 技术 | 作用 | 理由 |
|------|------|------|
| HTML | 页面结构、内容 | Web 三件套基础，没有替代品 |
| CSS | 外观、布局、响应式 | 同上 |
| JavaScript（少量） | 导航切换交互 | 仅用于页面切换，约 15-20 行 |

**不使用**任何框架、构建工具、npm 包。纯文本文件，浏览器直接打开即可。

## 4. 页面架构

四个页面，全部内容放在一个 HTML 文件中，通过 JavaScript 控制显示/隐藏实现"多页"效果。

```
首页     → 头像 + 名字 + 一句话简介 + 快捷入口按钮
关于我    → 自我介绍 + 技能标签
博客     → 文章卡片列表（标题 + 日期 + 摘要）
作品     → 项目卡片网格（名称 + 描述 + 链接）
```

共用组件：
- **顶部导航栏**：Logo/名字 + 四个页面链接，固定在页面顶部
- **底部页脚**：版权信息，居中显示

## 5. 视觉设计

### 配色（清爽极简风）

| 角色 | 颜色值 | 用途 |
|------|--------|------|
| 页面背景 | `#fafafa` | 全局背景 |
| 卡片背景 | `#ffffff` | 文章卡片、项目卡片 |
| 主文字 | `#2d2d2d` | 正文、标题 |
| 强调色 | `#4a6cf7` | 链接、按钮、导航高亮 |
| 辅强调 | `#6c63ff` | 渐变、悬停效果 |

### 字体

- 系统默认字体栈：`-apple-system, BlinkMacSystemFont, "Segoe UI", Roboto, sans-serif`
- 不使用外部字体，保证加载速度和跨平台一致性

## 6. 布局方案

```
┌────────────────────────────────────────┐
│  导航栏（固定顶部，最大宽 960px，居中）  │
│  Logo                       导航链接   │
├────────────────────────────────────────┤
│                                        │
│          内容区（最大宽 800px）         │
│                                        │
├────────────────────────────────────────┤
│      页脚 © 2026 · 名字 · 居中         │
└────────────────────────────────────────┘
```

### 响应式规则

| 断点 | 行为 |
|------|------|
| > 768px（电脑） | 内容居中，最大 800px，两侧留白 |
| ≤ 768px（手机） | 导航竖排，内容占满屏幕，卡片堆叠 |

通过 CSS `@media` 查询实现，约 20 行代码。

## 7. 各页面内容规格

### 首页
- 圆形头像（占位图，120×120px）
- 名字（大标题）
- 一句话介绍（副标题）
- 3 个快捷按钮（跳转到关于/博客/作品）
- 整体垂直居中

### 关于我
- 2 段自我介绍文字（占位文本）
- 技能标签：水平排列的小色块（如：C、C++、HTML、CSS）

### 博客
- 文章卡片纵向排列（初始 3 篇占位文章）
- 每张卡片包含：标题、日期、摘要文字
- 卡片间有间距，悬停有轻微上浮效果

### 作品
- 项目卡片网格排列（2 列，手机端 1 列）
- 每张卡片包含：项目名称、简短描述、链接
- 初始 2-4 个占位项目

## 8. 导航交互

- 当前选中页面在导航栏中高亮显示（下划线或颜色变化）
- 点击导航链接时，平滑切换页面内容（无页面刷新）
- 浏览器前进/后退按钮通过 URL hash（`#home`、`#about`、`#blog`、`#works`）支持

## 9. 文件结构

```
wangzhan/
├── index.html          ← 唯一的 HTML 文件（所有页面 + CSS + JS 都在里面）
└── docs/
    └── superpowers/
        └── specs/
            └── 2026-06-28-personal-website-design.md   ← 本设计文档
```

所有 CSS 和 JavaScript 写在 HTML 文件的 `<style>` 和 `<script>` 标签中，**保持单文件**——这是初学者最友好的方式，双击就能看，不需要任何工具。

## 10. 非功能要求

- 不需要服务器，静态文件即可运行
- 最终部署到 GitHub Pages（免费）
- 页面加载速度 < 1 秒（因为没有任何外部依赖）
- 内容使用占位文本，后续可随意替换

## 11. 不做的事项（本期）

- 不引入任何 CSS/JS 框架
- 不实现评论、搜索、RSS 等动态功能
- 不做暗色模式切换
- 不做多语言
- 不接入任何第三方服务（分析、广告等）

这些是后续迭代可以考虑的功能。
